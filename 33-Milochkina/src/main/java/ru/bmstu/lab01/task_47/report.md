# Задача 47. Поворот массива на 90 градусов

## Условие

**Вход:** двумерный массив `n x m`.

**Выход:** массив `m x n`, полученный поворотом на 90 градусов по часовой стрелке.

## Идея решения и структуры данных

Для исходной матрицы n × m создаётся результат m × n. Элемент [row][column] переносится в [column][n − 1 − row]. Такое отображение соответствует повороту по часовой стрелке.

## Расчёт асимптотики

**Время.** Два вложенных цикла выполняют n·m переносов, по O(1) на элемент. T(n, m) = O(nm).

**Память.** Результат содержит m·n элементов: O(nm). Рабочая память без результата — O(1).

Память входных данных не включается в дополнительную; память результата учитывается. Операции с фиксированными int/long считаются O(1).

## Примеры для ручной проверки

### Пример 1

Ввод:

```text
2 3
1 2 3
4 5 6
```

Ожидаемый вывод:

```text
4 1
5 2
6 3
```

**Что проверяет:** Размер меняется с 2 × 3 на 3 × 2

### Пример 2

Ввод:

```text
1 3
1 -2 3
```

Ожидаемый вывод:

```text
1
-2
3
```

**Что проверяет:** Одна строка превращается в столбец
