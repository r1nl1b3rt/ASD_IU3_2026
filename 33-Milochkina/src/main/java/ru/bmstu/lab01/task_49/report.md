# Задача 49. Сумма строк матрицы

## Условие

**Вход:** матрица `n x m` из целых чисел.

**Выход:** массив из `n` элементов — сумм строк матрицы.

## Идея решения и структуры данных

Для каждой строки поддерживается собственная сумма long в массиве результата. Все элементы строки прибавляются к соответствующей ячейке.

## Расчёт асимптотики

**Время.** Каждый из n·m элементов участвует ровно в одном сложении: T(n, m) = O(nm).

**Память.** Результат содержит n сумм long: O(n) дополнительной памяти. Рабочая память без результата — O(1).

Память входных данных не включается в дополнительную; память результата учитывается. Операции с фиксированными int/long считаются O(1).

## Примеры для ручной проверки

### Пример 1

Ввод:

```text
2 3
1 2 3
4 5 6
```

Ожидаемый вывод:

```text
6 15
```

**Что проверяет:** Суммы строк, а не столбцов

### Пример 2

Ввод:

```text
1 2
2147483647 2147483647
```

Ожидаемый вывод:

```text
4294967294
```

**Что проверяет:** Для суммы строки требуется long
