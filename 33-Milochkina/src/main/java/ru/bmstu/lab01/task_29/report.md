# Задача 29. Мода массива

## Условие

**Вход:** массив из `n` целых чисел.

**Выход:** наиболее часто встречающийся элемент. Если несколько — вывести наименьший по значению.

**Ограничения:** `1 ≤ n ≤ 10^4`.

## Идея решения и структуры данных

HashMap хранит частоты значений. При увеличении частоты очередного элемента он сравнивается с текущим ответом: большая частота побеждает, при равной частоте выбирается меньшее значение. Инициализация первым элементом поддерживает отрицательные числа и n = 1.

## Расчёт асимптотики

**Время.** Выполняется n шагов, на каждом — постоянное число обращений к HashMap. При O(1) на обращение в среднем ожидаемое время O(n).

**Память.** В таблице хранится u различных значений, u ≤ n. Дополнительная память O(u), в худшем случае O(n).

Память входных данных не включается в дополнительную; память результата учитывается. Операции с фиксированными int/long считаются O(1).

## Примеры для ручной проверки

### Пример 1

Ввод:

```text
6
3 1 3 2 3 2
```

Ожидаемый вывод:

```text
3
```

**Что проверяет:** Побеждает наиболее частое значение

### Пример 2

Ввод:

```text
4
5 2 5 2
```

Ожидаемый вывод:

```text
2
```

**Что проверяет:** При одинаковых частотах выбирается меньшее значение
