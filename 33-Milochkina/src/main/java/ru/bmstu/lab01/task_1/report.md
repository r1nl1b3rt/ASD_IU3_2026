# Задача 1. Максимум и минимум

## Условие

**Вход:** массив из `n` целых чисел.

**Выход:** минимальный и максимальный элементы массива.

**Ограничения:** `1 < n < 10^5`.

## Идея решения и структуры данных

Минимум и максимум инициализируются первым элементом. При просмотре массива каждое значение сравнивается с текущими минимумом и максимумом. Возвращается массив из двух чисел: сначала минимум, затем максимум. Другие структуры данных не нужны.

## Расчёт асимптотики

**Время.** Просматриваются n элементов, для каждого выполняется постоянное число сравнений. T(n) = c·n + d, поэтому время — O(n).

**Память.** Хранятся два экстремума и результат длины 2. Их количество не зависит от n, поэтому дополнительная память, включая результат, — O(1).

Память входных данных не включается в дополнительную; память результата учитывается. Операции с фиксированными int/long считаются O(1).

## Примеры для ручной проверки

### Пример 1

Ввод:

```text
5
4 -2 9 0 7
```

Ожидаемый вывод:

```text
-2 9
```

**Что проверяет:** Оба экстремума находятся внутри массива, присутствуют отрицательное число и ноль

### Пример 2

Ввод:

```text
3
7 7 7
```

Ожидаемый вывод:

```text
7 7
```

**Что проверяет:** Минимум и максимум могут совпадать
