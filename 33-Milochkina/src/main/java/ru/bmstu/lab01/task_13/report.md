# Задача 13. Сортировка выбором

## Условие

**Вход:** массив из `n` целых чисел.

**Выход:** массив, отсортированный по неубыванию.

**Требование:** реализовать сортировку выбором вручную, без использования встроенных функций сортировки.

## Идея решения и структуры данных

Для каждой позиции выбирается минимальный элемент оставшейся части массива и меняется местами с элементом на этой позиции. Сортировка выбором реализована вручную, без встроенной сортировки.

## Расчёт асимптотики

**Время.** Число сравнений равно (n − 1) + (n − 2) + … + 1 = n(n − 1)/2. Обменов не более n − 1. И лучший, и худший случаи имеют время O(n²).

**Память.** Используются индексы и временная переменная обмена. Сортировка выполняется на месте, дополнительная память — O(1).

Память входных данных не включается в дополнительную; память результата учитывается. Операции с фиксированными int/long считаются O(1).

## Примеры для ручной проверки

### Пример 1

Ввод:

```text
5
4 -2 9 0 7
```

Ожидаемый вывод:

```text
-2 0 4 7 9
```

**Что проверяет:** Проверка сортировки по неубыванию

### Пример 2

Ввод:

```text
5
3 1 3 1 2
```

Ожидаемый вывод:

```text
1 1 2 3 3
```

**Что проверяет:** Повторения должны сохраниться
