# Задача 3. Подсчёт вхождений

## Условие

**Вход:** массив из `n` целых чисел и число `x`.

**Выход:** количество элементов, равных `x`.

## Идея решения и структуры данных

Счётчик начинается с нуля. Для каждого элемента проверяется равенство x; при совпадении счётчик увеличивается. Полный просмотр обязателен, так как совпадения могут находиться в любом месте.

## Расчёт асимптотики

**Время.** Выполняется n сравнений и не более n увеличений счётчика. T(n) = c·n + d = O(n).

**Память.** Кроме входного массива используются только счётчик, x и переменная цикла. Дополнительная память — O(1).

Память входных данных не включается в дополнительную; память результата учитывается. Операции с фиксированными int/long считаются O(1).

## Примеры для ручной проверки

### Пример 1

Ввод:

```text
5
2 1 2 3 2
2
```

Ожидаемый вывод:

```text
3
```

**Что проверяет:** Вхождения расположены в разных частях массива

### Пример 2

Ввод:

```text
3
1 2 3
8
```

Ожидаемый вывод:

```text
0
```

**Что проверяет:** Если значение отсутствует, ответ равен нулю
