# Задача 56. Умножение матриц

## Условие

**Вход:** матрица `A` размера `n x m` и матрица `B` размера `m x k`.

**Выход:** матрица `C = A x B` размера `n x k`.

**Требование:** `O(n x m x k)` - по времени, `O(n x k)` - по памяти.

## Идея решения и структуры данных

Для каждой из n·k ячеек результата вычисляется скалярное произведение строки A и столбца B из m элементов. Отдельное произведение int вычисляется в long, сумма — в BigInteger, чтобы не терять точность при выходе за long.

## Расчёт асимптотики

**Время.** Три вложенных цикла выполняют n·k·m умножений и сложений. В стандартной арифметической модели время O(nmk), как требуется условием. С учётом битовой длины B накопителя точная оценка арифметики — O(nmk·B).

**Память.** Результат содержит n·k чисел. В стандартной модели дополнительная память O(nk), включая результат; при явном учёте битовой длины — O(nk·B) бит плюс ссылки и структура массивов. Дополнительные матрицы размером больше результата не создаются.

Память входных данных не включается в дополнительную; память результата учитывается. Операции с фиксированными int/long считаются O(1).

## Особенности реализации

На вход последовательно подаются размеры и элементы обеих матриц: n m, элементы A, затем m k, элементы B. Совместимость размеров гарантируется форматом задачи. BigInteger — класс стандартной библиотеки Java, а не сторонняя зависимость.

## Примеры для ручной проверки

### Пример 1

Ввод:

```text
2 3
1 2 3
4 5 6
3 2
7 8
9 10
11 12
```

Ожидаемый вывод:

```text
58 64
139 154
```

**Что проверяет:** Проверка умножения прямоугольных матриц 2 × 3 и 3 × 2

### Пример 2

Ввод:

```text
2 2
2 -3
4 5
2 2
1 0
0 1
```

Ожидаемый вывод:

```text
2 -3
4 5
```

**Что проверяет:** Умножение справа на единичную матрицу сохраняет исходную
