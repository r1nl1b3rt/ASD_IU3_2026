# Задача 16. Сортировка по модулю

## Условие

**Вход:** массив из `n` целых чисел.

**Выход:** массив, отсортированный по неубыванию модуля элементов. При равных модулях первым идёт отрицательный элемент.

## Идея решения и структуры данных

Элементы преобразуются в Integer[] и сортируются компаратором. Сначала сравниваются модули, затем сами значения по возрастанию: при равных модулях отрицательное значение оказывается первым. Модуль вычисляется после преобразования в long, чтобы корректно обработать Integer.MIN_VALUE.

## Расчёт асимптотики

**Время.** Преобразование и формирование результата занимают O(n). Сортировка объектов выполняет O(n log n) сравнений, каждое сравнение модулей занимает O(1). Итого O(n log n).

**Память.** Массив объектов, служебная память сортировки и возвращаемый int[] имеют размер O(n). Дополнительная память — O(n).

Память входных данных не включается в дополнительную; память результата учитывается. Операции с фиксированными int/long считаются O(1).

## Примеры для ручной проверки

### Пример 1

Ввод:

```text
5
2 -2 1 -1 0
```

Ожидаемый вывод:

```text
0 -1 1 -2 2
```

**Что проверяет:** При равном модуле отрицательное значение идёт раньше

### Пример 2

Ввод:

```text
3
-2147483648 2147483647 0
```

Ожидаемый вывод:

```text
0 2147483647 -2147483648
```

**Что проверяет:** Модуль Integer.MIN_VALUE должен вычисляться без переполнения int
