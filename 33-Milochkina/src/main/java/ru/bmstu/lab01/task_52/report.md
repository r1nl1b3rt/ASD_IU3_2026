# Задача 52. Минимум в каждом столбце

## Условие

**Вход:** матрица `n x m` из целых чисел.

**Выход:** массив из `m` элементов — минимальных значений в каждом столбце.

## Идея решения и структуры данных

Результат инициализируется копией первой строки. Далее каждый элемент сравнивается с текущим минимумом своего столбца.

## Расчёт асимптотики

**Время.** Копирование первой строки стоит O(m). Просмотр n строк по m элементов стоит O(nm). Итого O(m + nm) = O(nm).

**Память.** Результат содержит m минимумов: O(m) дополнительной памяти. Рабочая память без результата — O(1).

Память входных данных не включается в дополнительную; память результата учитывается. Операции с фиксированными int/long считаются O(1).

## Примеры для ручной проверки

### Пример 1

Ввод:

```text
2 3
1 2 3
4 5 6
```

Ожидаемый вывод:

```text
1 2 3
```

**Что проверяет:** Минимум ищется независимо по каждому столбцу

### Пример 2

Ввод:

```text
2 2
-5 -2
-8 -1
```

Ожидаемый вывод:

```text
-8 -2
```

**Что проверяет:** Проверка отрицательных минимумов в разных строках
