# Задача 48. Транспонирование матрицы

## Условие

**Вход:** квадратная матрица `n x n`.

**Выход:** транспонированная матрица.

**Требование:** транспонирование на месте, без создания нового массива.

## Идея решения и структуры данных

Перебираются только элементы строго выше главной диагонали. Каждый [i][j] меняется местами с [j][i]. Диагональ остаётся неизменной, новая матрица не создаётся.

## Расчёт асимптотики

**Время.** Выполняется (n − 1) + (n − 2) + … + 1 = n(n − 1)/2 обменов. T(n) = O(n²).

**Память.** Для обмена нужны два индекса и одно временное значение: O(1) рабочей памяти алгоритма. Вывод идёт по строкам и может использовать буфер O(n) символов для одной строки; входная матрица занимает O(n²).

Память входных данных не включается в дополнительную; память результата учитывается. Операции с фиксированными int/long считаются O(1).

## Примеры для ручной проверки

### Пример 1

Ввод:

```text
3
1 2 3
4 5 6
7 8 9
```

Ожидаемый вывод:

```text
1 4 7
2 5 8
3 6 9
```

**Что проверяет:** Строки и столбцы меняются ролями

### Пример 2

Ввод:

```text
2
1 2
2 3
```

Ожидаемый вывод:

```text
1 2
2 3
```

**Что проверяет:** Симметричная матрица не меняется
