# Задача 12. Пара с заданной суммой

## Условие

**Вход:** массив из `n` целых чисел и число `s`.

**Выход:** индексы `i < j`, для которых `a_i + a_j = s`. Если пар несколько — вывести пару с наименьшим `i`, а при равенстве — с наименьшим `j`. Если пары нет — вывести `-1 -1`.

## Идея решения и структуры данных

Массив просматривается справа налево. HashMap хранит для уже просмотренной правой части наименьший индекс каждого значения. Перед добавлением текущего элемента ищется дополнение s − a[i]. Найденная пара обновляет ответ: последующие шаги имеют меньший i, а сохранённый индекс дополнения даёт наименьший j.

## Расчёт асимптотики

**Время.** Выполняется n шагов с постоянным числом обращений к HashMap. При среднем O(1) на поиск и вставку ожидаемое время — O(n). Это оценка в среднем для хеш-таблицы, а не безусловная оценка каждой отдельной операции.

**Память.** HashMap хранит не более n различных значений с индексами. Ответ содержит два индекса. Дополнительная память — O(n).

Память входных данных не включается в дополнительную; память результата учитывается. Операции с фиксированными int/long считаются O(1).

## Примеры для ручной проверки

### Пример 1

Ввод:

```text
5
4 -2 9 0 7
7
```

Ожидаемый вывод:

```text
1 2
```

**Что проверяет:** Из нескольких пар выбирается пара с меньшим первым индексом

### Пример 2

Ввод:

```text
4
1 4 1 4
5
```

Ожидаемый вывод:

```text
0 1
```

**Что проверяет:** При одинаковом i выбирается наименьший возможный j
