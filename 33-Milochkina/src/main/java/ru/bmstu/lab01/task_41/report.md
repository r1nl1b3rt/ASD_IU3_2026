# Задача 41. Удаление элемента

## Условие

**Вход:** массив из `n` целых чисел и число `x`.

**Выход:** массив, из которого удалены все вхождения `x`.

## Идея решения и структуры данных

Массив просматривается слева направо. Значения, не равные x, записываются на следующую свободную позицию в начале того же массива. Возвращается количество оставшихся элементов, и выводится только этот префикс. Порядок сохраняется.

## Расчёт асимптотики

**Время.** Проверяются n элементов, записываются r оставшихся значений, где r ≤ n. T(n) = O(n + r) = O(n).

**Память.** Удаление выполняется с O(1) рабочей памятью на месте. Физическая длина массива не меняется. Формирование строки результата может занимать O(r).

Память входных данных не включается в дополнительную; память результата учитывается. Операции с фиксированными int/long считаются O(1).

## Примеры для ручной проверки

### Пример 1

Ввод:

```text
5
2 1 2 3 2
2
```

Ожидаемый вывод:

```text
1 3
```

**Что проверяет:** Все вхождения удаляются, порядок оставшихся сохраняется

### Пример 2

Ввод:

```text
3
7 7 7
7
```

Ожидаемый вывод: одна пустая строка

**Что проверяет:** После удаления всех элементов выводится одна пустая строка
