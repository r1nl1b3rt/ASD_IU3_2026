# Задача 34. Максимальная сумма подмассива

## Условие

**Вход:** массив из `n` целых чисел (могут быть отрицательные).

**Выход:** максимальная сумму непрерывного подмассива.

**Требование:** `O(n)` (алгоритм Кадане).

## Идея решения и структуры данных

Алгоритм Кадане хранит лучшую сумму подмассива, заканчивающегося в текущем элементе. Выбирается максимум между началом нового подмассива и продолжением предыдущего. Глобальный ответ обновляется на каждом шаге. Начальные значения берутся из первого элемента, поэтому выбирается непустой подмассив даже при всех отрицательных числах.

## Расчёт асимптотики

**Время.** После O(1) инициализации выполняется n − 1 шагов с постоянным числом сравнений и сложений. T(n) = O(n).

**Память.** Две суммы long и индекс занимают постоянный объём. Дополнительная память — O(1).

Память входных данных не включается в дополнительную; память результата учитывается. Операции с фиксированными int/long считаются O(1).

## Примеры для ручной проверки

### Пример 1

Ввод:

```text
9
-2 1 -3 4 -1 2 1 -5 4
```

Ожидаемый вывод:

```text
6
```

**Что проверяет:** Лучший непрерывный подмассив: 4, −1, 2, 1

### Пример 2

Ввод:

```text
4
-8 -3 -12 -5
```

Ожидаемый вывод:

```text
-3
```

**Что проверяет:** Пустой подмассив с суммой 0 не является допустимым ответом
