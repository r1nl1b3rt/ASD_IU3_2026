# Задача 58. Заполнение матрицы змейкой

## Условие

**Вход:** числа `n` и `m`.

**Выход:** матрица `n x m`, заполненная числами от 1 до `n x m` змейкой по строкам: первая строка слева направо, вторая — справа налево и т. д.

## Идея решения и структуры данных

Создаётся матрица long[n][m] и счётчик от 1. Чётные по индексу строки заполняются слева направо, нечётные — справа налево. Для каждой строки направление определяется формулой индекса столбца.

## Расчёт асимптотики

**Время.** Выполняется n·m записей с постоянным числом операций на запись. T(n, m) = O(nm). Вывод имеет тот же порядок сложности.

**Память.** Созданная матрица результата требует O(nm) памяти. Рабочая память без результата — O(1). При построчном выводе дополнительный текстовый буфер занимает O(m).

Память входных данных не включается в дополнительную; память результата учитывается. Операции с фиксированными int/long считаются O(1).

## Примеры для ручной проверки

### Пример 1

Ввод:

```text
3 4
```

Ожидаемый вывод:

```text
1 2 3 4
8 7 6 5
9 10 11 12
```

**Что проверяет:** Проверка смены направления на каждой строке

### Пример 2

Ввод:

```text
2 2
```

Ожидаемый вывод:

```text
1 2
4 3
```

**Что проверяет:** Нумерация начинается с 1, а не с 0
