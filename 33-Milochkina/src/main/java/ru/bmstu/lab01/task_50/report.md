# Задача 50. Сумма столбцов матрицы

## Условие

**Вход:** матрица `n x m` из целых чисел.

**Выход:** массив из `m` элементов — сумм столбцов матрицы.

## Идея решения и структуры данных

Создаётся массив long из m нулевых сумм. При просмотре каждой строки её элемент с индексом column прибавляется к сумме соответствующего столбца.

## Расчёт асимптотики

**Время.** Создание результата стоит O(m), просмотр матрицы — O(nm). При n ≥ 1 итоговое время O(nm + m) = O(nm).

**Память.** Результат содержит m сумм long: O(m) дополнительной памяти. Рабочая память без результата — O(1).

Память входных данных не включается в дополнительную; память результата учитывается. Операции с фиксированными int/long считаются O(1).

## Примеры для ручной проверки

### Пример 1

Ввод:

```text
2 3
1 2 3
4 5 6
```

Ожидаемый вывод:

```text
5 7 9
```

**Что проверяет:** Каждая позиция ответа соответствует столбцу

### Пример 2

Ввод:

```text
2 1
2147483647
2147483647
```

Ожидаемый вывод:

```text
4294967294
```

**Что проверяет:** Сумма одного столбца может не помещаться в int
