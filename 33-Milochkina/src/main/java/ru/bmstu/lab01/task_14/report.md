# Задача 14. Сортировка вставками

## Условие

**Вход:** массив из `n` целых чисел.

**Выход:** массив, отсортированный по невозрастанию.

**Требование:** реализовать сортировку вставками вручную.

## Идея решения и структуры данных

Слева поддерживается часть, отсортированная по невозрастанию. Очередной элемент сохраняется во временной переменной, меньшие значения сдвигаются вправо, затем элемент вставляется в освободившуюся позицию. Сортировка вставками реализована вручную.

## Расчёт асимптотики

**Время.** В худшем случае выполняются 1 + 2 + … + (n − 1) = n(n − 1)/2 сдвигов: O(n²). Если массив уже отсортирован по невозрастанию, каждый шаг требует только проверки: O(n).

**Память.** Нужны только индексы и вставляемое значение, поэтому дополнительная память — O(1).

Память входных данных не включается в дополнительную; память результата учитывается. Операции с фиксированными int/long считаются O(1).

## Примеры для ручной проверки

### Пример 1

Ввод:

```text
5
4 -2 9 0 7
```

Ожидаемый вывод:

```text
9 7 4 0 -2
```

**Что проверяет:** Нужен убывающий, а не возрастающий порядок

### Пример 2

Ввод:

```text
4
-3 -8 -1 -5
```

Ожидаемый вывод:

```text
-1 -3 -5 -8
```

**Что проверяет:** Проверка порядка для отрицательных чисел
