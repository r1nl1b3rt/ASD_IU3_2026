# Задача 57. Спиральный обход матрицы

## Условие

**Вход:** матрица `n x m` из целых чисел.

**Выход:** элементы матрицы, обойдённые по спирали от левого верхнего угла по часовой стрелке.

## Идея решения и структуры данных

Поддерживаются верхняя, нижняя, левая и правая границы ещё не обработанной части. Последовательно выписываются верхняя строка, правый столбец, нижняя строка в обратном направлении и левый столбец снизу вверх. После обработки каждой стороны её граница сдвигается. Проверки пересечения границ исключают повтор центральной строки или столбца.

## Расчёт асимптотики

**Время.** Каждый из n·m элементов записывается в результат ровно один раз. Суммарная длина всех обходов сторон равна nm, поэтому T(n, m) = O(nm), несмотря на несколько циклов.

**Память.** Результат содержит n·m значений: O(nm). Границы и позиция записи занимают O(1) рабочей памяти без результата; рекурсии нет.

Память входных данных не включается в дополнительную; память результата учитывается. Операции с фиксированными int/long считаются O(1).

## Примеры для ручной проверки

### Пример 1

Ввод:

```text
3 3
1 2 3
4 5 6
7 8 9
```

Ожидаемый вывод:

```text
1 2 3 6 9 8 7 4 5
```

**Что проверяет:** Центральный элемент должен попасть в ответ один раз

### Пример 2

Ввод:

```text
1 3
1 -2 3
```

Ожидаемый вывод:

```text
1 -2 3
```

**Что проверяет:** Одна строка не должна обходиться повторно
