# Задача 59. Определитель матрицы 3×3

## Условие

**Вход:** матрица `3 x 3` из целых чисел.

**Выход:** определитель матрицы.

## Идея решения и структуры данных

Определитель вычисляется разложением по первой строке: a00·(a11·a22 − a12·a21) − a01·(a10·a22 − a12·a20) + a02·(a10·a21 − a11·a20). Все произведения и разности вычисляются в BigInteger.

## Расчёт асимптотики

**Время.** Размер фиксирован: 3 × 3. Число арифметических операций постоянно и не зависит от входных значений. Поскольку исходные числа имеют фиксированный тип int, битовая длина результата также ограничена константой. Время — O(1).

**Память.** Фиксированное число BigInteger и матрица из девяти int занимают O(1) памяти при фиксированном размере входа.

Память входных данных не включается в дополнительную; память результата учитывается. Операции с фиксированными int/long считаются O(1).

## Особенности реализации

Вводятся только девять элементов матрицы по строкам, без предварительного ввода числа 3 или размеров.

## Примеры для ручной проверки

### Пример 1

Ввод:

```text
6 1 1
4 -2 5
2 8 7
```

Ожидаемый вывод:

```text
-306
```

**Что проверяет:** Проверка знаков при разложении по первой строке

### Пример 2

Ввод:

```text
1 2 3
2 4 6
4 5 6
```

Ожидаемый вывод:

```text
0
```

**Что проверяет:** При линейной зависимости строк определитель равен нулю
