# Задача 31. Скалярное произведение

## Условие

**Вход:** два массива одинаковой длины `n`.

**Выход:** скалярное произведение

## Идея решения и структуры данных

Для каждого индекса перемножаются соответствующие элементы двух массивов. Отдельное произведение int вычисляется в long, сумма накапливается в BigInteger для точности при выходе за пределы long.

## Расчёт асимптотики

**Время.** Для двух массивов длины n выполняется n умножений и n сложений. В стандартной арифметической модели время O(n); с учётом битовой длины накопителя — O(n·B).

**Память.** Количество рабочих накопителей постоянно: O(1) машинных величин при заданных ограничениях. В битовой модели дополнительная память результата — O(B).

Память входных данных не включается в дополнительную; память результата учитывается. Операции с фиксированными int/long считаются O(1).

## Особенности реализации

Для точных вычислений используется стандартный BigInteger. Если отдельно учитывать битовую стоимость, пусть B — максимальная длина промежуточного результата в битах. Тогда сложение и умножение на фиксированное 32-битное значение требуют O(B), а число бит результата необходимо учитывать в памяти. При заданных ограничениях int и n < 10^5 эти числа занимают постоянное число машинных слов.

## Примеры для ручной проверки

### Пример 1

Ввод:

```text
3
1 2 3
3
4 5 6
```

Ожидаемый вывод:

```text
32
```

**Что проверяет:** Перед каждым массивом вводится его размер; 1·4 + 2·5 + 3·6 = 32

### Пример 2

Ввод:

```text
2
1 1
2
5 -5
```

Ожидаемый вывод:

```text
0
```

**Что проверяет:** Произведения могут взаимно сокращаться
