# Задача 23. Проверка анаграммы массивов

## Условие

**Вход:** два массива одинаковой длины `n`.

**Выход:** `YES`, если один массив является перестановкой другого; `NO` иначе.

## Идея решения и структуры данных

Копии двух массивов сортируются, затем сравниваются поэлементно через Arrays.equals. После сортировки перестановки имеют одинаковые последовательности, включая одинаковое количество каждого повторяющегося значения.

## Расчёт асимптотики

**Время.** Для двух массивов длины n выполняются два копирования O(n), две сортировки O(n log n) и сравнение O(n). T(n) = O(n log n).

**Память.** Две копии и служебная память сортировок требуют O(n) дополнительной памяти.

Память входных данных не включается в дополнительную; память результата учитывается. Операции с фиксированными int/long считаются O(1).

## Примеры для ручной проверки

### Пример 1

Ввод:

```text
4
4 -2 9 0
4
9 0 -2 4
```

Ожидаемый вывод:

```text
YES
```

**Что проверяет:** Перед каждым массивом вводится его размер; порядок может различаться

### Пример 2

Ввод:

```text
3
1 1 2
3
1 2 2
```

Ожидаемый вывод:

```text
NO
```

**Что проверяет:** Совпадения набора различных значений недостаточно: важны частоты
