# Задача 18. Сортировка только чётных

## Условие

**Вход:** массив из `n` целых чисел.

**Выход:** тот же массив, в котором все чётные элементы отсортированы по неубыванию, а нечётные остались на своих местах.

## Идея решения и структуры данных

Из массива извлекаются только чётные значения, затем этот набор сортируется. Повторный просмотр исходного массива заменяет только чётные позиции очередными отсортированными значениями. Нечётные элементы остаются на своих местах.

## Расчёт асимптотики

**Время.** Пусть e — число чётных элементов. Два прохода стоят O(n), сортировка e значений — O(e log e). Итого O(n + e log e); в худшем случае O(n log n). При отсутствии чётных элементов время O(n).

**Память.** Для извлечённых чётных элементов и служебной памяти их сортировки требуется O(e) дополнительной памяти; в худшем случае O(n). Сам исходный массив изменяется.

Память входных данных не включается в дополнительную; память результата учитывается. Операции с фиксированными int/long считаются O(1).

## Примеры для ручной проверки

### Пример 1

Ввод:

```text
6
8 3 2 7 4 1
```

Ожидаемый вывод:

```text
2 3 4 7 8 1
```

**Что проверяет:** Меняются только позиции чётных значений

### Пример 2

Ввод:

```text
4
7 -3 5 1
```

Ожидаемый вывод:

```text
7 -3 5 1
```

**Что проверяет:** Если чётных значений нет, массив сохраняется
