# Задача 42. Вставка элемента в отсортированный массив

## Условие

**Вход:** отсортированный по неубыванию массив из `n` целых чисел и число `x`.

**Выход:** массив длины `n + 1`, в который `x` вставлен на правильную позицию.

**Требование:** использовать бинарный поиск для нахождения позиции.

## Идея решения и структуры данных

Бинарный поиск на полуинтервале находит первую позицию, значение в которой не меньше x. В новый массив копируются элементы до позиции, записывается x, затем копируется оставшаяся часть. Это сохраняет сортировку и все повторения.

## Расчёт асимптотики

**Время.** Бинарный поиск вдвое сокращает диапазон на каждом шаге: O(log n). Копируются ровно n исходных элементов, что стоит O(n). T(n) = O(log n + n) = O(n); весь алгоритм нельзя оценивать только как O(log n).

**Память.** Результирующий массив имеет n + 1 элементов: O(n). Сам бинарный поиск использует O(1) рабочей памяти.

Память входных данных не включается в дополнительную; память результата учитывается. Операции с фиксированными int/long считаются O(1).

## Примеры для ручной проверки

### Пример 1

Ввод:

```text
3
1 3 5
4
```

Ожидаемый вывод:

```text
1 3 4 5
```

**Что проверяет:** Вставка между существующими значениями

### Пример 2

Ввод:

```text
4
1 2 2 4
2
```

Ожидаемый вывод:

```text
1 2 2 2 4
```

**Что проверяет:** Вставка не удаляет одинаковые значения
