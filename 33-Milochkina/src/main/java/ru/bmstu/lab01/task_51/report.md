# Задача 51. Максимум в каждой строке

## Условие

**Вход:** матрица `n x m` из целых чисел.

**Выход:** массив из `n` элементов — максимальных значений в каждой строке.

## Идея решения и структуры данных

Максимум каждой строки инициализируется её первым элементом, затем сравнивается со всеми значениями этой строки. Инициализация нулём не используется, чтобы поддерживать полностью отрицательные строки.

## Расчёт асимптотики

**Время.** В каждой из n строк просматриваются m элементов. T(n, m) = O(nm).

**Память.** Массив n максимумов требует O(n) памяти. Кроме результата используются только индексы и текущие значения: O(1).

Память входных данных не включается в дополнительную; память результата учитывается. Операции с фиксированными int/long считаются O(1).

## Примеры для ручной проверки

### Пример 1

Ввод:

```text
2 3
1 2 3
4 5 6
```

Ожидаемый вывод:

```text
3 6
```

**Что проверяет:** Максимум ищется независимо в каждой строке

### Пример 2

Ввод:

```text
2 2
-5 -2
-8 -1
```

Ожидаемый вывод:

```text
-2 -1
```

**Что проверяет:** Ноль не должен подменять максимум отрицательной строки
