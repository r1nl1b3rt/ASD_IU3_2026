# Задача 9. Проверка отсортированности

## Условие

**Вход:** массив из `n` целых чисел.

**Выход:** `YES`, если массив неубывающий; `NO` иначе.

## Идея решения и структуры данных

Сравниваются соседние элементы. Если очередной элемент меньше предыдущего, сразу возвращается false. Равные элементы допустимы. Если нарушений нет, возвращается true; main выводит YES или NO.

## Расчёт асимптотики

**Время.** В худшем случае проверяются n − 1 соседних пар: O(n). Если нарушение найдено в первой паре, лучший случай — O(1).

**Память.** Используется только индекс прохода. Дополнительная память — O(1).

Память входных данных не включается в дополнительную; память результата учитывается. Операции с фиксированными int/long считаются O(1).

## Примеры для ручной проверки

### Пример 1

Ввод:

```text
4
1 2 2 5
```

Ожидаемый вывод:

```text
YES
```

**Что проверяет:** Неубывание допускает равные соседние элементы

### Пример 2

Ввод:

```text
4
1 3 2 4
```

Ожидаемый вывод:

```text
NO
```

**Что проверяет:** Достаточно одной нарушающей порядок соседней пары
