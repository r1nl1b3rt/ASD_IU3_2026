# Задача 8. Фильтрация по знаку

## Условие

**Вход:** массив из `n` целых чисел.

**Выход:** два массива — из положительных и из отрицательных элементов, в исходном порядке. Нули не включать ни в один.

## Идея решения и структуры данных

Создаются временные массивы для положительных и отрицательных значений. Каждый элемент добавляется в соответствующий массив, нули пропускаются. Копирование до фактических размеров убирает неиспользованные ячейки. Порядок сохраняется, поскольку просмотр идёт слева направо.

## Расчёт асимптотики

**Время.** Один проход стоит O(n). Копирование p положительных и q отрицательных элементов стоит O(p + q), где p + q ≤ n. Итого T(n) = O(n).

**Память.** Два временных массива длины n и результаты общей длины не более n требуют O(n) дополнительной памяти.

Память входных данных не включается в дополнительную; память результата учитывается. Операции с фиксированными int/long считаются O(1).

## Примеры для ручной проверки

### Пример 1

Ввод:

```text
6
3 -2 0 5 -1 0
```

Ожидаемый вывод:

```text
3 5
-2 -1
```

**Что проверяет:** Нули исключены, порядок внутри обеих групп сохранён

### Пример 2

Ввод:

```text
3
-3 2 -1
```

Ожидаемый вывод:

```text
2
-3 -1
```

**Что проверяет:** Числа не сортируются внутри групп
