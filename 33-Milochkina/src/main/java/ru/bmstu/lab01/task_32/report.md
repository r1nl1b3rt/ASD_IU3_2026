# Задача 32. Сумма произведений пар

## Условие

**Вход:** массив из `n` целых чисел.

**Выход:** сумма произведений всех пар элементов `a_i * a_j` для `i < j`.

**Требование:** `O(n)`

## Идея решения и структуры данных

При движении слева направо хранится сумма P всех предыдущих элементов. Текущий элемент a[j] добавляет ко всем парам вклад P·a[j], после чего включается в P. Так каждая пара i < j учитывается ровно один раз. Результат хранится в BigInteger, префиксная сумма допустимых int — в long.

## Расчёт асимптотики

**Время.** Обрабатывается n элементов с постоянным числом арифметических операций на каждом шаге. В стандартной арифметической модели T(n) = O(n), что соответствует требованию. В битовой модели вычисления BigInteger требуют O(n·B). Вложенного перебора пар нет.

**Память.** Используются префиксная сумма и накопитель результата: O(1) машинных величин при данных ограничениях. При учёте длины результата — O(B) бит.

Память входных данных не включается в дополнительную; память результата учитывается. Операции с фиксированными int/long считаются O(1).

## Особенности реализации

Для точных вычислений используется стандартный BigInteger. Если отдельно учитывать битовую стоимость, пусть B — максимальная длина промежуточного результата в битах. Тогда сложение и умножение на фиксированное 32-битное значение требуют O(B), а число бит результата необходимо учитывать в памяти. При заданных ограничениях int и n < 10^5 эти числа занимают постоянное число машинных слов.

## Примеры для ручной проверки

### Пример 1

Ввод:

```text
3
1 2 3
```

Ожидаемый вывод:

```text
11
```

**Что проверяет:** Учитываются пары 1·2, 1·3 и 2·3, их сумма равна 11

### Пример 2

Ввод:

```text
3
2 -3 4
```

Ожидаемый вывод:

```text
-10
```

**Что проверяет:** Отрицательные вклады должны сохранять знак
