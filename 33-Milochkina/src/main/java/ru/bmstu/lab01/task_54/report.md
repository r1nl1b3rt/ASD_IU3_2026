# Задача 54. Сумма элементов на главной диагонали

## Условие

**Вход:** квадратная матрица `n x n`.

**Выход:** сумма элементов на главной диагонали.

## Идея решения и структуры данных

Суммируются элементы matrix[i][i]. Накопитель имеет тип long. Остальные элементы матрицы в вычислении не участвуют.

## Расчёт асимптотики

**Время.** Вычислительный метод выполняет n сложений: O(n). Полная программа всё равно считывает n² элементов матрицы, поэтому время с учётом ввода — O(n²).

**Память.** Сам метод использует накопитель и индекс: O(1) дополнительной памяти. Считанная входная матрица занимает O(n²).

Память входных данных не включается в дополнительную; память результата учитывается. Операции с фиксированными int/long считаются O(1).

## Примеры для ручной проверки

### Пример 1

Ввод:

```text
3
1 2 3
4 5 6
7 8 9
```

Ожидаемый вывод:

```text
15
```

**Что проверяет:** Главная диагональ: 1, 5, 9

### Пример 2

Ввод:

```text
2
2147483647 0
0 2147483647
```

Ожидаемый вывод:

```text
4294967294
```

**Что проверяет:** Проверка накопления в long
