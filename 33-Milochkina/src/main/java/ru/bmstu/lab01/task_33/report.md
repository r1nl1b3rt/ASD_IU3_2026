# Задача 33. Количество инверсий

## Условие

**Вход:** массив из `n` целых чисел.

**Выход:** количество пар `(i, j)` таких, что `i < j` и `a_i > a_j`.

**Требование:** `O(n log n)` (через модификацию сортировки слиянием).

## Идея решения и структуры данных

Модифицированная сортировка слиянием обрабатывает копию массива. При взятии меньшего элемента из правой половины к счётчику добавляется число оставшихся элементов левой половины. Для равных элементов инверсии не добавляются. Счётчик имеет тип long.

## Расчёт асимптотики

**Время.** Две половины обрабатываются рекурсивно, их слияние стоит O(n): T(n) = 2T(n/2) + O(n). На каждом из O(log n) уровней суммарно обрабатывается O(n) элементов, поэтому T(n) = O(n log n).

**Память.** Копия и буфер слияния содержат по n элементов: O(n). Стек рекурсии имеет глубину O(log n). Итого O(n + log n) = O(n) дополнительной памяти.

Память входных данных не включается в дополнительную; память результата учитывается. Операции с фиксированными int/long считаются O(1).

## Примеры для ручной проверки

### Пример 1

Ввод:

```text
5
2 4 1 3 5
```

Ожидаемый вывод:

```text
3
```

**Что проверяет:** Инверсии: (2,1), (4,1), (4,3), где пары указаны значениями

### Пример 2

Ввод:

```text
4
2 1 2 1
```

Ожидаемый вывод:

```text
3
```

**Что проверяет:** Равные значения не образуют инверсии
