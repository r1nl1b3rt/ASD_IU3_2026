# Задача 7. Второй максимум

## Условие

**Вход:** массив из `n` целых чисел. Все элементы различны.

**Выход:** второй по величине элемент массива.

## Идея решения и структуры данных

По первым двум элементам определяются текущие максимум и второй максимум. Далее новый элемент либо становится максимумом со сдвигом прежнего максимума, либо обновляет только второе значение. Все элементы по условию различны.

## Расчёт асимптотики

**Время.** Инициализация занимает O(1), затем выполняется n − 2 шагов с постоянным числом сравнений. T(n) = O(n).

**Память.** Используются два значения и переменная цикла. Дополнительная память — O(1).

Память входных данных не включается в дополнительную; память результата учитывается. Операции с фиксированными int/long считаются O(1).

## Примеры для ручной проверки

### Пример 1

Ввод:

```text
5
4 -2 9 0 7
```

Ожидаемый вывод:

```text
7
```

**Что проверяет:** Второй максимум меньше 9 и больше остальных значений

### Пример 2

Ввод:

```text
4
-8 -3 -12 -5
```

Ожидаемый вывод:

```text
-5
```

**Что проверяет:** Инициализация не должна ошибочно считать ноль максимумом отрицательного массива
