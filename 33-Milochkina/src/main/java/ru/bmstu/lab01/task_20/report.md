# Задача 20. Сортировка подсчётом

## Условие

**Вход:** массив из `n` целых чисел.

**Выход:** массив, отсортированный по неубыванию.

**Требование:** реализовать сортировку подсчётом.

## Идея решения и структуры данных

Находятся минимум min и максимум max. Создаётся массив K = max − min + 1 счётчиков; значение a соответствует индексу a − min, поэтому поддерживаются отрицательные числа. После подсчёта повторений значения восстанавливаются в исходном массиве по возрастанию. Это обычная сортировка подсчётом без переключения на другую сортировку.

## Расчёт асимптотики

**Время.** Поиск границ и подсчёт повторений дают два прохода по n элементам. Создание счётчиков требует O(K), восстановление проходит K значений и записывает ровно n элементов. T(n, K) = O(n + K); утверждать просто O(n) при неограниченном K нельзя.

**Память.** Массив счётчиков содержит K элементов: O(K) дополнительной памяти. Отдельный массив результата не создаётся.

Память входных данных не включается в дополнительную; память результата учитывается. Операции с фиксированными int/long считаются O(1).

## Особенности реализации

В условии не ограничен диапазон значений. Реализация требует массива из K счётчиков: при K > Integer.MAX_VALUE выбрасывается IllegalArgumentException, а большой меньший диапазон может не поместиться в память. Разность границ вычисляется в long. Работа для произвольного полного диапазона int не гарантируется; это ограничение текущей реализации, а не дополнительное условие преподавателя.

## Примеры для ручной проверки

### Пример 1

Ввод:

```text
7
3 -2 0 3 -5 -2 1
```

Ожидаемый вывод:

```text
-5 -2 -2 0 1 3 3
```

**Что проверяет:** Проверка сдвига индексов для отрицательных чисел и сохранения повторений

### Пример 2

Ввод:

```text
3
7 7 7
```

Ожидаемый вывод:

```text
7 7 7
```

**Что проверяет:** При одном уникальном значении K = 1
