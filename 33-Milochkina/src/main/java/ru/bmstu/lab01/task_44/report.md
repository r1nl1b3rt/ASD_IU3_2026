# Задача 44. Чередование знаков

## Условие

**Вход:** массив из `n` целых чисел, содержащий равное число положительных и отрицательных элементов (нулей нет).

**Выход:** массив, в котором положительные и отрицательные элементы чередуются, начиная с положительного. Относительный порядок внутри положительных и отрицательных сохранить.

## Идея решения и структуры данных

Создаётся результат длины n. Положительные числа записываются на позиции 0, 2, 4, отрицательные — на 1, 3, 5. Каждая группа заполняется при просмотре исходного массива слева направо, поэтому её относительный порядок сохраняется. Равенство размеров групп и отсутствие нулей гарантированы условием.

## Расчёт асимптотики

**Время.** Один просмотр выполняет n проверок знака и n записей. T(n) = O(n).

**Память.** Результат содержит n элементов: O(n) дополнительной памяти. Два указателя требуют O(1) рабочей памяти без результата.

Память входных данных не включается в дополнительную; память результата учитывается. Операции с фиксированными int/long считаются O(1).

## Примеры для ручной проверки

### Пример 1

Ввод:

```text
6
1 2 3 -1 -2 -3
```

Ожидаемый вывод:

```text
1 -1 2 -2 3 -3
```

**Что проверяет:** Нужно чередование с положительного элемента

### Пример 2

Ввод:

```text
6
-5 7 3 -2 -9 4
```

Ожидаемый вывод:

```text
7 -5 3 -2 4 -9
```

**Что проверяет:** Проверка сохранения порядка внутри обеих групп
