# Задача 6. Элементы больше среднего

## Условие

**Вход:** массив из `n` целых чисел.

**Выход:** количество элементов, строго больших среднего арифметического всех элементов. Гарантируется, что среднее — целое число (сумма делится на `n`).

## Идея решения и структуры данных

Первым проходом вычисляется сумма в long и среднее значение. По условию сумма делится на n без остатка. Вторым проходом подсчитываются элементы, строго большие среднего.

## Расчёт асимптотики

**Время.** Два последовательных прохода дают n + n = 2n итераций. T(n) = c₁·n + c₂·n + d = O(n), а не O(n²), поскольку циклы не вложены.

**Память.** Сумма, среднее и счётчик занимают постоянный объём. Дополнительная память — O(1).

Память входных данных не включается в дополнительную; память результата учитывается. Операции с фиксированными int/long считаются O(1).

## Примеры для ручной проверки

### Пример 1

Ввод:

```text
3
1 2 3
```

Ожидаемый вывод:

```text
1
```

**Что проверяет:** Среднее равно 2; равный среднему элемент не учитывается

### Пример 2

Ввод:

```text
3
7 7 7
```

Ожидаемый вывод:

```text
0
```

**Что проверяет:** При одинаковых элементах ни один не больше среднего
