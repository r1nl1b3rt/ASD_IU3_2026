# Задача 11. Ближайший к среднему

## Условие

**Вход:** массив из `n` целых чисел.

**Выход:** элемент массива, ближайший к среднему арифметическому. Если несколько — вывести первый по индексу.

**Ограничения:** среднее может быть дробным.

## Идея решения и структуры данных

Первым проходом вычисляется сумма S в long. Вместо дробного расстояния |a[i] − S/n| сравнивается |a[i]·n − S|: умножение на положительное n не меняет порядок расстояний. Ответ обновляется только при строго меньшем расстоянии, что сохраняет первый индекс при равенстве.

## Расчёт асимптотики

**Время.** Суммирование выполняется за n шагов, поиск ближайшего значения — ещё за n. T(n) = O(n + n) = O(n).

**Память.** Хранятся сумма, текущее расстояние и найденное значение. Дополнительная память — O(1).

Память входных данных не включается в дополнительную; память результата учитывается. Операции с фиксированными int/long считаются O(1).

## Примеры для ручной проверки

### Пример 1

Ввод:

```text
5
4 -2 9 0 7
```

Ожидаемый вывод:

```text
4
```

**Что проверяет:** Среднее равно 3,6; ближайшим является 4

### Пример 2

Ввод:

```text
2
0 4
```

Ожидаемый вывод:

```text
0
```

**Что проверяет:** Оба значения на расстоянии 2 от среднего; выбирается первое
