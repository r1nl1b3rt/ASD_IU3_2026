# Задача 22. Сортировка по частоте

## Условие

**Вход:** массив из `n` целых чисел.

**Выход:** массив, отсортированный по убыванию частоты встречаемости элементов. При равных частотах — по возрастанию значения.

## Идея решения и структуры данных

HashMap подсчитывает частоту каждого значения. Затем Integer[] сортируется компаратором: сначала частота по убыванию, при равенстве — само значение по возрастанию. Итог преобразуется в int[].

## Расчёт асимптотики

**Время.** Подсчёт частот в среднем занимает O(n). При среднем O(1) на получение частоты компаратор работает за O(1), а сортировка — за O(n log n). Итоговая оценка в среднем — O(n log n).

**Память.** Хеш-таблица содержит u ≤ n ключей. Массив объектов, память сортировки и результат имеют размер O(n). Всего дополнительная память — O(n).

Память входных данных не включается в дополнительную; память результата учитывается. Операции с фиксированными int/long считаются O(1).

## Примеры для ручной проверки

### Пример 1

Ввод:

```text
6
4 1 4 2 1 4
```

Ожидаемый вывод:

```text
4 4 4 1 1 2
```

**Что проверяет:** Сначала идут значения с большей частотой

### Пример 2

Ввод:

```text
6
3 -1 2 3 2 -1
```

Ожидаемый вывод:

```text
-1 -1 2 2 3 3
```

**Что проверяет:** При равных частотах нужен возрастающий порядок значений
