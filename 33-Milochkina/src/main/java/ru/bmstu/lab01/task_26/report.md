# Задача 26. Произведение элементов

## Условие

**Вход:** массив из `n` целых чисел.

**Выход:** произведение всех элементов по модулю `10^9 + 7`.

## Идея решения и структуры данных

Используется модуль M = 1 000 000 007. Каждый множитель приводится к остатку от 0 до M − 1 через Math.floorMod, затем накопленное произведение снова берётся по модулю. Промежуточное произведение меньше M² и помещается в long.

## Расчёт асимптотики

**Время.** Для каждого из n элементов выполняется постоянное число операций с long. T(n) = O(n).

**Память.** Хранятся модуль, текущий остаток и множитель. Дополнительная память — O(1).

Память входных данных не включается в дополнительную; память результата учитывается. Операции с фиксированными int/long считаются O(1).

## Примеры для ручной проверки

### Пример 1

Ввод:

```text
3
2 3 4
```

Ожидаемый вывод:

```text
24
```

**Что проверяет:** Произведение меньше модуля сохраняется

### Пример 2

Ввод:

```text
3
-1 2 3
```

Ожидаемый вывод:

```text
1000000001
```

**Что проверяет:** Для отрицательного произведения выводится неотрицательный остаток
