# Задача 21. K-й наименьший элемент

## Условие

**Вход:** массив из `n` целых чисел и число `k` (`1 ≤ k ≤ n`).

**Выход:** `k`-й наименьший элемент массива.

**Требование:** отсортировать массив и взять элемент с индексом `k - 1`.

## Идея решения и структуры данных

Создаётся копия массива, которая сортируется по неубыванию. Из неё возвращается элемент с индексом k − 1. Повторяющиеся значения занимают отдельные позиции.

## Расчёт асимптотики

**Время.** Копирование стоит O(n), сортировка — O(n log n), обращение по индексу — O(1). T(n) = O(n + n log n + 1) = O(n log n).

**Память.** Копия содержит n элементов. Вместе со служебной памятью сортировки дополнительная память — O(n).

Память входных данных не включается в дополнительную; память результата учитывается. Операции с фиксированными int/long считаются O(1).

## Примеры для ручной проверки

### Пример 1

Ввод:

```text
5
9 -2 4 0 7
3
```

Ожидаемый вывод:

```text
4
```

**Что проверяет:** После сортировки третий элемент равен 4

### Пример 2

Ввод:

```text
4
3 1 1 2
2
```

Ожидаемый вывод:

```text
1
```

**Что проверяет:** Одинаковые значения учитываются как разные элементы
