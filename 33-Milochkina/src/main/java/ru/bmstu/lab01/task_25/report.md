# Задача 25. Сумма элементов

## Условие

**Вход:** массив из `n` целых чисел.

**Выход:** сумма всех элементов.

## Идея решения и структуры данных

Все элементы последовательно добавляются к накопителю long. Этот тип выбран, поскольку сумма допустимого количества значений int может выйти за пределы int.

## Расчёт асимптотики

**Время.** Выполняется n сложений: T(n) = c·n + d = O(n).

**Память.** Используется один накопитель long и переменная цикла. Дополнительная память — O(1).

Память входных данных не включается в дополнительную; память результата учитывается. Операции с фиксированными int/long считаются O(1).

## Примеры для ручной проверки

### Пример 1

Ввод:

```text
5
4 -2 9 0 7
```

Ожидаемый вывод:

```text
18
```

**Что проверяет:** Проверка сложения чисел разных знаков

### Пример 2

Ввод:

```text
2
2147483647 2147483647
```

Ожидаемый вывод:

```text
4294967294
```

**Что проверяет:** Результат не помещается в int
