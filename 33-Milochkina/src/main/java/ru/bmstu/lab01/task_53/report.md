# Задача 53. Седловые точки

## Условие

**Вход:** матрица `n x m` из целых чисел.

**Выход:** все седловые точки — элементы, одновременно минимальные в своей строке и максимальные в своём столбце. Вывести в формате `(индекс_строки, индекс_столбца, значение)`.

## Идея решения и структуры данных

Первый проход одновременно находит минимумы всех строк и максимумы всех столбцов. Второй проход выбирает элементы, совпадающие с обоими соответствующими экстремумами. Каждая найденная точка сохраняется как тройка: строка, столбец, значение. Равные экстремумы не исключаются.

## Расчёт асимптотики

**Время.** Инициализация массивов требует O(n + m), два прохода — O(nm + nm). T(n, m) = O(n + m + 2nm) = O(nm) для непустой матрицы.

**Память.** Для экстремумов нужно O(n + m), для s найденных точек и списка результата — O(s). Всего O(n + m + s) дополнительной памяти. В худшем случае s = nm, например у матрицы одинаковых значений.

Память входных данных не включается в дополнительную; память результата учитывается. Операции с фиксированными int/long считаются O(1).

## Особенности реализации

Индексы начинаются с нуля. Каждая точка выводится отдельной строкой в формате (строка, столбец, значение). Если точек нет, вывод отсутствует.

## Примеры для ручной проверки

### Пример 1

Ввод:

```text
2 3
1 2 3
4 5 6
```

Ожидаемый вывод:

```text
(1, 0, 4)
```

**Что проверяет:** Число 4 минимально во второй строке и максимально в первом столбце

### Пример 2

Ввод:

```text
2 2
1 3
4 2
```

Ожидаемый вывод отсутствует

**Что проверяет:** В этой матрице ни один элемент не удовлетворяет обоим условиям
