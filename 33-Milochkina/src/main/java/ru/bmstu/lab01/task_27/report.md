# Задача 27. Сумма квадратов

## Условие

**Вход:** массив из `n` целых чисел.

**Выход:** сумма квадратов всех элементов.

## Идея решения и структуры данных

Квадрат каждого int сначала вычисляется в long, поскольку отдельный квадрат помещается в этот тип. Затем он прибавляется к BigInteger: сумма нескольких квадратов может превысить long.

## Расчёт асимптотики

**Время.** Выполняются n вычислений квадрата и n сложений. В модели арифметики ограниченной разрядности время — O(n). С учётом длины BigInteger в битах — O(n·B).

**Память.** Количество накопителей постоянно: O(1) машинных величин при заданных ограничениях. При учёте битовой длины BigInteger требуется O(B) бит дополнительной памяти, включая результат.

Память входных данных не включается в дополнительную; память результата учитывается. Операции с фиксированными int/long считаются O(1).

## Особенности реализации

Для точных вычислений используется стандартный BigInteger. Если отдельно учитывать битовую стоимость, пусть B — максимальная длина промежуточного результата в битах. Тогда сложение и умножение на фиксированное 32-битное значение требуют O(B), а число бит результата необходимо учитывать в памяти. При заданных ограничениях int и n < 10^5 эти числа занимают постоянное число машинных слов.

## Примеры для ручной проверки

### Пример 1

Ввод:

```text
4
-2 0 3 4
```

Ожидаемый вывод:

```text
29
```

**Что проверяет:** Квадраты отрицательных значений неотрицательны

### Пример 2

Ввод:

```text
3
-2147483648 -2147483648 -2147483648
```

Ожидаемый вывод:

```text
13835058055282163712
```

**Что проверяет:** Даже long недостаточен для точной суммы
