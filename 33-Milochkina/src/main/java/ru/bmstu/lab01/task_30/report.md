# Задача 30. Дисперсия

## Условие

**Вход:** массив из `n` целых чисел.

**Выход:** выборочную дисперсию по формуле.

В используемом файле задания сама формула не приведена; допущение реализации указано ниже.

## Идея решения и структуры данных

Первый проход вычисляет среднее ā = S/n, второй суммирует квадраты отклонений. Реализована формула D = (1/n)·Σ(a[i] − ā)². Такой способ не использует вычитание двух близких больших сумм квадратов.

## Расчёт асимптотики

**Время.** Два последовательных прохода имеют n + n = 2n итераций, каждая содержит постоянное число арифметических операций. T(n) = O(n).

**Память.** Сумма, среднее, отклонение и накопитель занимают постоянный объём. Дополнительная память — O(1).

Память входных данных не включается в дополнительную; память результата учитывается. Операции с фиксированными int/long считаются O(1).

## Особенности реализации

В исходном условии написано «выборочную дисперсию по формуле», но формула отсутствует. Деление на n — явное допущение текущего решения. Если преподаватель требует исправленную дисперсию, знаменатель должен быть n − 1; тогда необходимо согласованно изменить реализацию, тесты и этот отчёт.

## Примеры для ручной проверки

### Пример 1

Ввод:

```text
4
1 2 3 4
```

Ожидаемый вывод:

```text
1.25
```

**Что проверяет:** Среднее 2,5, сумма квадратов отклонений 5, деление на n = 4 даёт 1,25

### Пример 2

Ввод:

```text
3
7 7 7
```

Ожидаемый вывод:

```text
0.0
```

**Что проверяет:** У одинаковых элементов все отклонения равны нулю
