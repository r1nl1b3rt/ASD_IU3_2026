# Задача 4. Все индексы элемента

## Условие

**Вход:** массив из `n` целых чисел и число `x`.

**Выход:** все индексы элементов, равных `x`, в порядке возрастания.

## Идея решения и структуры данных

При просмотре слева направо индексы совпадений записываются во временный массив длины n. После прохода Arrays.copyOf оставляет только найденные k индексов. Порядок индексов автоматически возрастающий.

## Расчёт асимптотики

**Время.** Просмотр занимает O(n), копирование k найденных индексов — O(k). Поскольку 0 ≤ k ≤ n, T(n, k) = O(n + k) = O(n).

**Память.** Временный массив содержит n ячеек, возвращаемый — k. В момент копирования существуют оба массива: O(n + k) = O(n) дополнительной памяти. Объём результата отдельно — O(k).

Память входных данных не включается в дополнительную; память результата учитывается. Операции с фиксированными int/long считаются O(1).

## Примеры для ручной проверки

### Пример 1

Ввод:

```text
5
2 1 2 3 2
2
```

Ожидаемый вывод:

```text
0 2 4
```

**Что проверяет:** Проверка индексации с нуля и порядка всех совпадений

### Пример 2

Ввод:

```text
3
1 2 3
8
```

Ожидаемый вывод: одна пустая строка

**Что проверяет:** Если совпадений нет, программа выводит одну пустую строку
