# Задача 39. Циклический сдвиг вправо

## Условие

**Вход:** массив из `n` целых чисел и число `k`.

**Выход:** массив, циклически сдвинутый вправо на `k` позиций.

**Требование:** учесть, что `k` может быть больше `n`.

## Идея решения и структуры данных

Сдвиг нормализуется по длине. Сначала разворачивается весь массив, затем первые k элементов и оставшаяся часть. Последние k элементов исходного массива оказываются в начале с сохранением взаимного порядка.

## Расчёт асимптотики

**Время.** Длины трёх разворачиваемых диапазонов равны n, k и n − k. T(n) = O(n + k + n − k) = O(n).

**Память.** Используются операции на месте и постоянное число переменных. Дополнительная память алгоритма — O(1).

Память входных данных не включается в дополнительную; память результата учитывается. Операции с фиксированными int/long считаются O(1).

## Особенности реализации

Оценка O(1) относится к самому преобразованию. Входной массив хранится отдельно; буфер формирования текстовой строки при выводе может требовать O(n) памяти.

## Примеры для ручной проверки

### Пример 1

Ввод:

```text
5
1 2 3 4 5
2
```

Ожидаемый вывод:

```text
4 5 1 2 3
```

**Что проверяет:** Последние два элемента переходят в начало

### Пример 2

Ввод:

```text
5
1 2 3 4 5
12
```

Ожидаемый вывод:

```text
4 5 1 2 3
```

**Что проверяет:** Проверка нормализации сдвига больше длины
