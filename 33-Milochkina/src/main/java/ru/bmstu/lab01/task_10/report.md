# Задача 10. Поиск элемента с условием

## Условие

**Вход:** массив из `n` целых чисел и число `k`.

**Выход:** индекс последнего элемента, кратного `k`. Если такого нет — вывести `-1`.

**Ограничения:** `k ≠ 0`.

## Идея решения и структуры данных

Массив просматривается справа налево. Первый найденный элемент с остатком от деления на k, равным нулю, имеет наибольший индекс. Если совпадений нет, возвращается -1. По условию k не равен нулю.

## Расчёт асимптотики

**Время.** Лучший случай — O(1), если последний элемент подходит. В худшем случае выполняется n проверок делимости, поэтому время — O(n).

**Память.** Кроме входного массива нужны индекс и делитель. Дополнительная память — O(1).

Память входных данных не включается в дополнительную; память результата учитывается. Операции с фиксированными int/long считаются O(1).

## Примеры для ручной проверки

### Пример 1

Ввод:

```text
5
3 4 6 7 9
3
```

Ожидаемый вывод:

```text
4
```

**Что проверяет:** Нужен последний подходящий индекс, а не первый

### Пример 2

Ввод:

```text
3
1 5 7
2
```

Ожидаемый вывод:

```text
-1
```

**Что проверяет:** Проверка отсутствия кратных элементов
