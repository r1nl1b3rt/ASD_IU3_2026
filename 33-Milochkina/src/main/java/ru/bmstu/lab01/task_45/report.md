# Задача 45. Разбиение по опорному элементу

## Условие

**Вход:** массив из `n` целых чисел и опорное значение `p`.

**Выход:** массив, переставленный так, что сначала идут все элементы `< p`, затем `= p`, затем `> p`. Относительный порядок внутри групп не важен.

**Требование:** `O(n)`, `O(1)` доп. памяти.

## Идея решения и структуры данных

Алгоритм трёхцветного флага поддерживает группы меньше p, равно p, необработанный диапазон и группу больше p. Элемент меньше p переносится в левую группу, больше p — в правую; равный p остаётся в средней. После обмена с правым краем текущий индекс не увеличивается: пришедшее значение ещё не проверено.

## Расчёт асимптотики

**Время.** На каждой итерации необработанный диапазон сокращается ровно на один элемент: увеличивается current или уменьшается upper. Поэтому выполняется n итераций с O(1) действиями, T(n) = O(n).

**Память.** Используются три указателя, p и временное значение обмена. Дополнительная память алгоритма — O(1), перестановка выполняется на месте.

Память входных данных не включается в дополнительную; память результата учитывается. Операции с фиксированными int/long считаются O(1).

## Особенности реализации

Оценка O(1) относится к самому преобразованию. Входной массив хранится отдельно; буфер формирования текстовой строки при выводе может требовать O(n) памяти. Порядок внутри групп условием не фиксирован. Ручной пример показывает один допустимый результат, а автоматические тесты проверяют границы групп и сохранность мультимножества значений.

## Примеры для ручной проверки

### Пример 1

Ввод:

```text
6
3 1 2 3 4 0
3
```

Ожидаемый вывод:

```text
1 2 0 3 3 4
```

**Что проверяет:** Любая перестановка с теми же тремя группами также допустима

### Пример 2

Ввод:

```text
3
7 7 7
7
```

Ожидаемый вывод:

```text
7 7 7
```

**Что проверяет:** Проверка случая, когда все элементы относятся к средней группе

## Автоматические тесты

Для задачи подготовлено **7 автоматических тестов JUnit 5**. Проверяются: все три группы, отсутствие одной из групп, отсутствие p в массиве, одинаковые значения, сохранение количества элементов и границы int.
