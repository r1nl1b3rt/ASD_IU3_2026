# Задача 35. Префиксные суммы

## Условие

**Вход:** массив из `n` целых чисел и `q` запросов вида `[l, r]` — диапазон индексов.

**Выход:** для каждого запроса — сумму элементов с индексами от `l` до `r` включительно.

**Требование:** предпосчёт префиксных сумм, затем `O(1)` на запрос.

## Идея решения и структуры данных

Создаётся массив P длины n + 1: P[0] = 0, P[i + 1] = P[i] + a[i]. Сумма включительного диапазона [l, r] равна P[r + 1] − P[l]. Запросы читаются и выводятся по одному, их ответы не накапливаются в отдельном массиве.

## Расчёт асимптотики

**Время.** Построение P выполняет n сложений: O(n). Каждый из q запросов содержит два обращения по индексу и одно вычитание: O(1) на запрос. Общее время T(n, q) = O(n + q).

**Память.** Префиксный массив имеет n + 1 элементов long: O(n) дополнительной памяти. Обработка одного запроса требует O(1) рабочей памяти.

Память входных данных не включается в дополнительную; память результата учитывается. Операции с фиксированными int/long считаются O(1).

## Примеры для ручной проверки

### Пример 1

Ввод:

```text
5
4 -2 9 0 7
4
0 4
1 3
2 2
3 4
```

Ожидаемый вывод:

```text
18
7
9
7
```

**Что проверяет:** Проверяются включительные границы и индексация с нуля

### Пример 2

Ввод:

```text
2
2147483647 2147483647
1
0 1
```

Ожидаемый вывод:

```text
4294967294
```

**Что проверяет:** Префиксные суммы должны храниться в long
