# Задача 19. Объединение двух отсортированных массивов

## Условие

**Вход:** два массива, каждый отсортирован по неубыванию; размеры `n` и `m`.

**Выход:** один отсортированный массив — результат слияния.

**Требование:** `O(n + m)`.

## Идея решения и структуры данных

Используются два указателя на текущие элементы отсортированных массивов. Меньший элемент записывается в результат, после чего сдвигается соответствующий указатель. Когда один массив заканчивается, дописывается остаток другого.

## Расчёт асимптотики

**Время.** Пусть длины равны n и m. Каждый элемент записывается в результат ровно один раз, выполняется не более n + m − 1 сравнений. T(n, m) = O(n + m), как требуется.

**Память.** Возвращаемый массив содержит n + m элементов: O(n + m). Рабочая память без результата — O(1), так как используются только указатели.

Память входных данных не включается в дополнительную; память результата учитывается. Операции с фиксированными int/long считаются O(1).

## Примеры для ручной проверки

### Пример 1

Ввод:

```text
3
1 3 5
3
2 4 6
```

Ожидаемый вывод:

```text
1 2 3 4 5 6
```

**Что проверяет:** При вводе перед каждым массивом указан его размер

### Пример 2

Ввод:

```text
3
1 2 2
3
1 2 3
```

Ожидаемый вывод:

```text
1 1 2 2 2 3
```

**Что проверяет:** Слияние не должно удалять повторения
