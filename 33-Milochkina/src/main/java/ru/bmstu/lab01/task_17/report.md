# Задача 17. Сортировка по сумме цифр

## Условие

**Вход:** массив из `n` неотрицательных целых чисел.

**Выход:** массив, отсортированный по возрастанию суммы цифр каждого числа. При равных суммах — сохранить исходный порядок.

## Идея решения и структуры данных

Неотрицательные значения преобразуются в Integer[]. Стабильная сортировка объектов сравнивает только суммы цифр. При одинаковом ключе компаратор возвращает 0, поэтому исходный порядок таких элементов сохраняется.

## Расчёт асимптотики

**Время.** Пусть D — максимальное число цифр. Один вызов вычисления суммы цифр стоит O(D), а сравнений O(n log n): O(n·D·log n). Для int D ≤ 10, поэтому при данных ограничениях время — O(n log n).

**Память.** Массив объектов, служебная память стабильной сортировки и возвращаемый массив требуют O(n) дополнительной памяти.

Память входных данных не включается в дополнительную; память результата учитывается. Операции с фиксированными int/long считаются O(1).

## Примеры для ручной проверки

### Пример 1

Ввод:

```text
6
22 21 13 12 4 30
```

Ожидаемый вывод:

```text
21 12 30 22 13 4
```

**Что проверяет:** Порядок внутри групп с суммами 3 и 4 должен сохраниться

### Пример 2

Ввод:

```text
4
10 0 1 0
```

Ожидаемый вывод:

```text
0 0 10 1
```

**Что проверяет:** Нули идут первыми; 10 и 1 сохраняют взаимный порядок
