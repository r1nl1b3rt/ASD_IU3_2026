# Задача 36. Бегущая сумма

## Условие

**Вход:** массив из `n` целых чисел.

**Выход:** массив той же длины, где `i`-й элемент равен сумме первых `i + 1` элементов исходного массива.

## Идея решения и структуры данных

При одном проходе поддерживается накопленная сумма long. После добавления очередного элемента она записывается в соответствующую ячейку нового long[]. В отличие от задачи 35 начального дополнительного нуля в результате нет.

## Расчёт асимптотики

**Время.** Каждый из n элементов один раз прибавляется и записывается: T(n) = O(n). Вывод n сумм также занимает O(n) при ограниченной длине long.

**Память.** Результирующий массив содержит n значений long: O(n). Рабочая память без результата — O(1). Буфер текстового вывода также может занимать O(n).

Память входных данных не включается в дополнительную; память результата учитывается. Операции с фиксированными int/long считаются O(1).

## Примеры для ручной проверки

### Пример 1

Ввод:

```text
5
4 -2 9 0 7
```

Ожидаемый вывод:

```text
4 2 11 11 18
```

**Что проверяет:** Каждая позиция содержит сумму от начала до неё включительно

### Пример 2

Ввод:

```text
3
1 -1 2
```

Ожидаемый вывод:

```text
1 0 2
```

**Что проверяет:** Накопленная сумма может уменьшаться и обращаться в ноль
