# Задача 55. Сумма элементов на побочной диагонали

## Условие

**Вход:** квадратная матрица `n x n`.

**Выход:** сумма элементов на побочной диагонали (от правого верхнего угла к левому нижнему).

## Идея решения и структуры данных

Для строки i выбирается элемент столбца n − 1 − i. Значения побочной диагонали складываются в long.

## Расчёт асимптотики

**Время.** Метод просматривает n диагональных значений, T(n) = O(n). С учётом предварительного чтения всей матрицы полная программа работает за O(n²).

**Память.** Сам метод использует O(1) дополнительной памяти. Хранение входной матрицы требует O(n²) и учитывается отдельно.

Память входных данных не включается в дополнительную; память результата учитывается. Операции с фиксированными int/long считаются O(1).

## Примеры для ручной проверки

### Пример 1

Ввод:

```text
3
1 2 3
4 5 6
7 8 9
```

Ожидаемый вывод:

```text
15
```

**Что проверяет:** Побочная диагональ: 3, 5, 7

### Пример 2

Ввод:

```text
2
0 2147483647
2147483647 0
```

Ожидаемый вывод:

```text
4294967294
```

**Что проверяет:** Проверка правильных индексов и long для суммы
