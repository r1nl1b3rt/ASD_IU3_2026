# Задача 28. Медиана массива

## Условие

**Вход:** массив из `n` целых чисел.

**Выход:** медиана массива. При нечётном `n` — элемент посередине после сортировки. При чётном `n` — среднее арифметическое двух центральных элементов (как число с плавающей точкой).

## Идея решения и структуры данных

Сортируется копия массива. Для нечётной длины возвращается центральный элемент, для чётной — среднее двух центральных. Перед сложением центральных значений одно преобразуется в long, затем выполняется деление на 2.0.

## Расчёт асимптотики

**Время.** Копирование требует O(n), сортировка O(n log n), получение медианы O(1). Итого O(n log n).

**Память.** Копия массива и служебная память сортировки требуют O(n) дополнительной памяти.

Память входных данных не включается в дополнительную; память результата учитывается. Операции с фиксированными int/long считаются O(1).

## Примеры для ручной проверки

### Пример 1

Ввод:

```text
4
4 1 3 2
```

Ожидаемый вывод:

```text
2.5
```

**Что проверяет:** Для чётной длины нужен средний результат двух центральных значений

### Пример 2

Ввод:

```text
2
2147483647 2147483647
```

Ожидаемый вывод:

```text
2.147483647E9
```

**Что проверяет:** Сложение центральных значений не должно переполнять int
