# Задача 43. Перемещение нулей в конец

## Условие

**Вход:** массив из `n` целых чисел.

**Выход:** тот же массив, в котором все нули перемещены в конец, порядок остальных элементов сохранён.

**Требование:** модификация на месте.

## Идея решения и структуры данных

Первым проходом ненулевые значения переносятся в начало исходного массива в исходном порядке. Затем все оставшиеся позиции заполняются нулями. Запись всегда идёт не правее текущего чтения, поэтому непрочитанные элементы не теряются.

## Расчёт асимптотики

**Время.** Просмотр выполняет n шагов, заполнение хвоста — z шагов, где z ≤ n. T(n) = O(n + z) = O(n).

**Память.** Нужны только индекс записи и переменная текущего значения. Рабочая память алгоритма — O(1), новый массив не создаётся.

Память входных данных не включается в дополнительную; память результата учитывается. Операции с фиксированными int/long считаются O(1).

## Особенности реализации

Оценка O(1) относится к самому преобразованию. Входной массив хранится отдельно; буфер формирования текстовой строки при выводе может требовать O(n) памяти.

## Примеры для ручной проверки

### Пример 1

Ввод:

```text
5
0 1 0 3 12
```

Ожидаемый вывод:

```text
1 3 12 0 0
```

**Что проверяет:** Порядок 1, 3, 12 сохраняется

### Пример 2

Ввод:

```text
4
0 0 -1 -2
```

Ожидаемый вывод:

```text
-1 -2 0 0
```

**Что проверяет:** Отрицательные значения тоже считаются ненулевыми
