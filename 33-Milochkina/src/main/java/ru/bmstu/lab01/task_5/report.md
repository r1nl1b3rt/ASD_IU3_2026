# Задача 5. Сумма элементов на чётных позициях

## Условие

**Вход:** массив из `n` целых чисел.

**Выход:** сумма элементов с чётными индексами (0, 2, 4, …).

## Идея решения и структуры данных

Перебираются индексы 0, 2, 4 и так далее с шагом 2. Значения складываются в long, чтобы сумма нескольких int не переполнила int.

## Расчёт асимптотики

**Время.** Цикл выполняет ceil(n/2) итераций. T(n) = c·ceil(n/2) + d, поэтому время — O(n), несмотря на пропуск половины элементов.

**Память.** Нужны только индекс и накопитель long. Дополнительная память — O(1).

Память входных данных не включается в дополнительную; память результата учитывается. Операции с фиксированными int/long считаются O(1).

## Примеры для ручной проверки

### Пример 1

Ввод:

```text
5
4 -2 9 0 7
```

Ожидаемый вывод:

```text
20
```

**Что проверяет:** Суммируются элементы с индексами 0, 2 и 4, а не элементы с чётными значениями

### Пример 2

Ввод:

```text
4
1 100 3 100
```

Ожидаемый вывод:

```text
4
```

**Что проверяет:** Элементы с нечётными индексами не влияют на результат
