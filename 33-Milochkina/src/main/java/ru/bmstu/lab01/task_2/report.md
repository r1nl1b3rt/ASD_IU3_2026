# Задача 2. Индекс первого вхождения

## Условие

**Вход:** массив из `n` целых чисел и число `x`.

**Выход:** индекс первого элемента, равного `x`. Если такого нет — вывести `-1`.

## Идея решения и структуры данных

Массив просматривается слева направо. При первом совпадении с x возвращается текущий индекс, поэтому более поздние совпадения не меняют ответ. Если просмотр завершён без совпадения, возвращается -1.

## Расчёт асимптотики

**Время.** Если x расположен в начале, выполняется одна проверка: лучший случай O(1). Если x отсутствует или находится в конце, проверяются n элементов: худший случай O(n).

**Память.** Используются индекс и искомое значение, новые массивы не создаются. Дополнительная память — O(1).

Память входных данных не включается в дополнительную; память результата учитывается. Операции с фиксированными int/long считаются O(1).

## Примеры для ручной проверки

### Пример 1

Ввод:

```text
5
4 -2 9 -2 7
-2
```

Ожидаемый вывод:

```text
1
```

**Что проверяет:** При повторениях нужен индекс первого вхождения

### Пример 2

Ввод:

```text
3
1 2 3
8
```

Ожидаемый вывод:

```text
-1
```

**Что проверяет:** Проверка отсутствующего значения
