# Задача 15. Пузырьковая сортировка с подсчётом обменов

## Условие

**Вход:** массив из `n` целых чисел.

**Выход:** отсортированный массив и количество обменов, выполненных в процессе пузырьковой сортировки.

**Требование:** реализовать пузырьковую сортировку с досрочным выходом, если массив уже отсортирован.

## Идея решения и структуры данных

Соседние элементы меняются местами, если нарушают неубывание. Каждый обмен увеличивает счётчик long. После прохода без обменов алгоритм завершается досрочно. Равные элементы не обмениваются.

## Расчёт асимптотики

**Время.** В худшем случае число сравнений ограничено суммой (n − 1) + … + 1 = n(n − 1)/2, поэтому время O(n²). Для уже отсортированного массива выполняется один проход без обменов: O(n).

**Память.** Счётчик обменов, флаг и индексы занимают постоянный объём. Сортировка выполняется на месте, дополнительная память — O(1).

Память входных данных не включается в дополнительную; память результата учитывается. Операции с фиксированными int/long считаются O(1).

## Примеры для ручной проверки

### Пример 1

Ввод:

```text
4
4 3 2 1
```

Ожидаемый вывод:

```text
1 2 3 4
6
```

**Что проверяет:** Для обратного порядка нужно 4·3/2 = 6 обменов

### Пример 2

Ввод:

```text
3
1 2 3
```

Ожидаемый вывод:

```text
1 2 3
0
```

**Что проверяет:** Проверка досрочного завершения без обменов
