# Задача 40. Удаление дубликатов

## Условие

**Вход:** отсортированный по неубыванию массив из `n` целых чисел.

**Выход:** массив без дубликатов, сохраняя порядок.

**Требование:** `O(n)`, модификация исходного массива на месте.

## Идея решения и структуры данных

В отсортированном массиве одинаковые значения расположены рядом. Указатель length задаёт число уже записанных уникальных элементов. Очередное отличающееся значение помещается в начало массива на позицию length. Метод возвращает логическую длину; физическая длина Java-массива не меняется. Выводится только значимый префикс.

## Расчёт асимптотики

**Время.** Каждый из n элементов проверяется не более одного раза и записывается не более одного раза. T(n) = O(n). Вывод u уникальных элементов стоит O(u), u ≤ n, и не меняет итоговую оценку.

**Память.** Преобразование использует только индексы и выполняется на месте: O(1) рабочей памяти. Буфер вывода значимого префикса может занимать O(u).

Память входных данных не включается в дополнительную; память результата учитывается. Операции с фиксированными int/long считаются O(1).

## Примеры для ручной проверки

### Пример 1

Ввод:

```text
5
1 1 2 2 3
```

Ожидаемый вывод:

```text
1 2 3
```

**Что проверяет:** Выводится только уникальная часть, а не оставшийся хвост исходного массива

### Пример 2

Ввод:

```text
3
7 7 7
```

Ожидаемый вывод:

```text
7
```

**Что проверяет:** При полном совпадении остаётся один элемент
