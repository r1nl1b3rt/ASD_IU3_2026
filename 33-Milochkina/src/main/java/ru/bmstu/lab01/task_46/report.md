# Задача 46. Сжатие диапазона

## Условие

**Вход:** массив из `n` целых чисел.

**Выход:** массив той же длины, где каждый элемент заменён его рангом — номером в отсортированном порядке без дубликатов (начиная с 0).

**Пример:** `[100, 50, 100, 300]` → `[1, 0, 1, 2]`.

## Идея решения и структуры данных

Копия массива сортируется. При проходе по ней каждому новому значению присваивается очередной ранг в HashMap, начиная с 0. Второй просмотр исходного массива заменяет значения найденными рангами в новом массиве. Повторения получают одинаковый ранг.

## Расчёт асимптотики

**Время.** Копирование и заполнение результата стоят O(n), сортировка — O(n log n). Построение и чтение HashMap в среднем занимают O(n). Итоговая оценка в среднем — O(n log n).

**Память.** Копия, таблица не более чем из n ключей и результат длины n требуют O(n) дополнительной памяти.

Память входных данных не включается в дополнительную; память результата учитывается. Операции с фиксированными int/long считаются O(1).

## Примеры для ручной проверки

### Пример 1

Ввод:

```text
4
100 50 100 300
```

Ожидаемый вывод:

```text
1 0 1 2
```

**Что проверяет:** Отсортированные уникальные значения: 50, 100, 300

### Пример 2

Ввод:

```text
4
-5 -1 -5 -3
```

Ожидаемый вывод:

```text
0 2 0 1
```

**Что проверяет:** Порядок исходных позиций сохраняется, меняются только значения
