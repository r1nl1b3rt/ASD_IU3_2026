# Задача 37. Разворот массива

## Условие

**Вход:** массив из `n` целых чисел.

**Выход:** массив, записанный в обратном порядке.

**Требование:** выполнить разворот на месте, без создания нового массива.

## Идея решения и структуры данных

Два указателя начинают движение с противоположных концов массива. Элементы меняются местами, указатели сближаются до встречи. Общий ArrayTransforms.reverse изменяет исходный массив без создания нового.

## Расчёт асимптотики

**Время.** Выполняется floor(n/2) обменов, каждый стоит O(1). T(n) = O(n).

**Память.** Нужны два указателя и временная переменная обмена. Рабочая память алгоритма — O(1), новый массив не создаётся.

Память входных данных не включается в дополнительную; память результата учитывается. Операции с фиксированными int/long считаются O(1).

## Особенности реализации

Оценка O(1) относится к самому преобразованию. Входной массив хранится отдельно; буфер формирования текстовой строки при выводе может требовать O(n) памяти.

## Примеры для ручной проверки

### Пример 1

Ввод:

```text
5
1 2 3 4 5
```

Ожидаемый вывод:

```text
5 4 3 2 1
```

**Что проверяет:** При нечётной длине центральный элемент остаётся в центре

### Пример 2

Ввод:

```text
4
2 1 2 1
```

Ожидаемый вывод:

```text
1 2 1 2
```

**Что проверяет:** Проверка парного обмена при повторениях
