# Задача 24. Чётно-нечётная сортировка

## Условие

**Вход:** массив из `n` целых чисел.

**Выход:** массив, в котором все чётные элементы отсортированы по возрастанию и идут первыми, а нечётные отсортированы по убыванию и идут после.

## Идея решения и структуры данных

Integer[] сортируется компаратором. Чётные значения образуют первую группу и упорядочиваются по возрастанию, нечётные — вторую и упорядочиваются по убыванию. Нечётность проверяется как остаток, не равный нулю, поэтому отрицательные нечётные тоже попадают в правильную группу.

## Расчёт асимптотики

**Время.** Преобразования массива стоят O(n), сортировка с постоянным по времени компаратором — O(n log n). Итоговое время — O(n log n).

**Память.** Массив объектов, память сортировки и результирующий int[] требуют O(n) дополнительной памяти.

Память входных данных не включается в дополнительную; память результата учитывается. Операции с фиксированными int/long считаются O(1).

## Примеры для ручной проверки

### Пример 1

Ввод:

```text
6
5 2 7 4 1 0
```

Ожидаемый вывод:

```text
0 2 4 7 5 1
```

**Что проверяет:** Проверяются порядок групп и разные направления сортировки

### Пример 2

Ввод:

```text
6
-3 -2 -7 -4 -1 0
```

Ожидаемый вывод:

```text
-4 -2 0 -1 -3 -7
```

**Что проверяет:** Отрицательные нечётные сортируются по убыванию
