# Задача 38. Циклический сдвиг влево

## Условие

**Вход:** массив из `n` целых чисел и число `k`.

**Выход:** массив, циклически сдвинутый влево на `k` позиций.

**Требование:** `O(n)`, `O(1)` доп. памяти (через тройной разворот).

## Идея решения и структуры данных

Сдвиг нормализуется по длине: k = floorMod(k, n). Массив разбивается на блоки A длины k и B длины n − k. Разворачиваются A, B и затем весь массив: AB превращается в BA. Для пустого массива предусмотрен ранний выход.

## Расчёт асимптотики

**Время.** Нормализация стоит O(1). Три разворота обрабатывают диапазоны длин k, n − k и n. T(n) = O(k + n − k + n) = O(n).

**Память.** Все развороты выполняются на месте, хранятся лишь индексы и временное значение. Дополнительная память алгоритма — O(1), как требуется.

Память входных данных не включается в дополнительную; память результата учитывается. Операции с фиксированными int/long считаются O(1).

## Особенности реализации

Оценка O(1) относится к самому преобразованию. Входной массив хранится отдельно; буфер формирования текстовой строки при выводе может требовать O(n) памяти.

## Примеры для ручной проверки

### Пример 1

Ввод:

```text
5
1 2 3 4 5
2
```

Ожидаемый вывод:

```text
3 4 5 1 2
```

**Что проверяет:** Первые два элемента переходят в конец

### Пример 2

Ввод:

```text
5
1 2 3 4 5
12
```

Ожидаемый вывод:

```text
3 4 5 1 2
```

**Что проверяет:** Сдвиг 12 эквивалентен сдвигу 12 mod 5 = 2
